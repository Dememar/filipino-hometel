About Us

This website is a final project for our subject Application Development. It is a sample hotel reservation site where users can get a simple idea of how an online booking system looks and works. We built this project using HTML for structure, CSS for design and appearance, and JavaScript for button functions and logic.

The Developers

This website was created by Dememar Solomon and Cahren Sagrit, computer science students at Jay School. Building this project helped them improve their skills and knowledge, preparing them for more coding challenges ahead.

We hope you enjoy exploring the website. Thank you for visiting!
